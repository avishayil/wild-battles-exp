# docs/assets

Put the README banner here as **`banner.png`** (the README references
`docs/assets/banner.png`). Recommended ~1240×420 px (displayed at 620 wide for retina).

> ⚠️ **Do not commit copyrighted artwork.** This project distributes no game assets (see
> [`../../DISCLAIMER.md`](../../DISCLAIMER.md)). Use **original** art, a self-made logo, or
> imagery you have the right to redistribute — not ripped Pokémon sprites, screenshots, or
> official key art. Keeping this repo asset-clean is part of its legal footing.
