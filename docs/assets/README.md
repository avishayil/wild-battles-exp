# docs/assets

Project branding. The README banner lives here:

- **`banner.svg`** — the editable source of truth (original abstract artwork; pure SVG).
- **`banner.png`** — a 1240×420 raster of the SVG, referenced by the README for reliable
  rendering on GitHub. Regenerate it from the SVG with:
  `rsvg-convert -w 1240 -h 420 banner.svg -o banner.png`

The banner is **original art** — stylized, non-recognizable creature silhouettes, an energy
burst, and EXP motes. It deliberately uses **no** official Pokémon/Nintendo logos, key art,
Poké Ball iconography, or copied game UI.

> ⚠️ **Asset policy.** Keep this folder to original, non-infringing art only — no ripped
> sprites, official logos, or key art. Self-captured **gameplay screenshots and the demo
> recording** (used to document the mod) live separately under
> [`../media/`](../media/) and are covered by the demonstration-media clause in
> [`../../DISCLAIMER.md`](../../DISCLAIMER.md); they depict game visuals owned by their rights
> holders and are not under this repo's license.
